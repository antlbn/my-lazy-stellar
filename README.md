# my-lazy-stellar

Stargazing spot finder built on the Google Agent Development Kit (ADK).

## Problem Statement
Иногда хочется сорваться и посмотреть на звёзды, но нет времени искать место и сверять погоду, особенно в незнакомых районах. Хочется быстро получить 3–5 вариантов, не тратя вечер на ресёрч.

## Why Agents
Агенты могут взять на себя семантическую работу: собрать предпочтения, искать по разрозненным источникам, учитывать ограничения и возвращать структурированный список точек с погодой — без единой базы знаний.

## What I Created (Architecture)
- Оркестратор общается с пользователем и собирает контекст, затем координирует шаги.
- Search Agent (ADK built-in google_search tool) достаёт кандидатов и нормализует формат.
- Weather Agent вызывает кастомный `fetch_astro_weather_7timer` по каждой точке (astro-weather API).
- Итог: оркестратор сводит результаты, помечает погоду/доступность и выдаёт shortlist.
- Локально: `adk web` playground с hot-reload (`make playground`). Деплой: обёртка под Agent Engine (`app/agent_engine_app.py`).

## Demo
- Локальный playground: `make install && make playground`
- Eval сет для проверки: `app/baseline.evalset.json`

## The Build
- Основано на Google Agent Starter Pack (ADK mode), затем упаковано сюда.
- 1 главный агент + 2 подагента (поиск, погода); инструменты: встроенный ADK search, кастомный weather.
- Сессии и логирование/трейсинг через ADK + Cloud Logging/Trace; готовность к MCP time‑серверу при подключении.
